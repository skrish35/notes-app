# 📒 Notes Manager

A fast, modern, and intuitive Notes Management application built with **React** and **Vite**. The app lets you create, organize, and prioritize notes, with persistence via the browser's LocalStorage.

---

## Overview

- **Create, edit, delete** notes with a simple UI.
- Assign **priority levels** (Low, Medium, High) and **categories** to each note.
- **Filter** notes by priority, category, or search term.
- All data is stored locally, so your notes persist across sessions without a backend.

## Installation

### Prerequisites

- **Node.js** (v14 or newer)
- **npm** (comes with Node) or **yarn**

### Steps

```bash
# Clone the repository
git clone https://github.com/skrish35/notes-app.git
cd notes-app

# Install dependencies
npm install   # or `yarn`
```

### Running the Development Server

```bash
npm run dev   # Starts Vite dev server at http://localhost:5173
```

### Building for Production

```bash
npm run build   # Generates optimized assets in the `dist` folder
npm run preview # Preview the production build locally
```

## Usage

### Creating a Note
1. Click the **"Add Note"** button.
2. Enter a title, content, select a priority, and choose or create a category.
3. Click **"Save"**. The note appears in the list and is saved to LocalStorage.

### Editing / Deleting
- Click the **pencil icon** on a note to edit it.
- Click the **trash icon** to delete a note (confirmation required).

### Filtering & Searching
- Use the **priority** and **category** dropdowns to filter notes.
- Type in the **search bar** to find notes by title or content.
